# Working agreement — api.support.cafe

The operating contract for **any** coding agent working in this repository. This file is
the single source of truth for the rules: Codex, Cursor and Gemini CLI read `AGENTS.md`
natively, and Claude Code loads it through the `@AGENTS.md` import in
[`CLAUDE.md`](CLAUDE.md). **Never fork these rules into a per-vendor file.**

Backend for **support.cafe** — a support-desk service. WebSocket RPC (not REST), with a Telegram bridge and an MCP surface for agents.

## Invariants (don't break these)

- **Never hand-edit `src/codegen/`.** Those types are generated by `endpoint-gen` from the
  RON schemas. Edit the schema and regenerate; a hand-edit is silently lost on the next run.
- **A WorkTable schema change is a deployment event, not just a code change.** This repo has
  **7 `worktable!` definitions, 6 with `persist: true`** (on-disk data). If one of
  those moves, the change **must** ship with a WT data migration script — verified *before*
  merge, not discovered at deploy. Full guidance and the exact checks:
  [`docs/worktable-schema-and-deploy.md`](docs/worktable-schema-and-deploy.md).
- **`endpoint-libs` and `honey_id-types` move in lockstep.** `honey_id-types` re-exports
  endpoint-libs' `WsRequest`/`WsResponse` traits, so bumping one alone puts two incompatible
  copies of endpoint-libs in the graph and the traits stop matching. Bump both, and check
  `grep -c 'name = "endpoint-libs"' Cargo.lock` is `1`.
- **Don't enable an `endpoint-libs` feature this service doesn't use.** A new feature upstream
  is not a reason to turn it on here; keep the feature list minimal.

## Build & run

```bash
cargo build
cargo test
cargo fmt && cargo clippy --all-targets    # run after every change
```

### Code generation

```bash
./scripts/utils/regenerate_endpoints.sh
# Install: cargo install --git https://github.com/pathscale/EndpointGen.git
```

Descriptions in the RON are **not** cosmetic — an endpoint description becomes the MCP tool
description an agent reads to decide whether to call it. `endpoint-gen` 1.10+ fails
generation on blank descriptions (`--allow-empty-descriptions` to bypass).

## Architecture

`handlers/` endpoint handlers · `service/` business logic · `db/` WorkTable schemas · `codegen/` generated types · `config/` layered config · `acme.rs` TLS

## Verification

Run what you build before reporting it done. Type-checks and tests verify code correctness,
not feature correctness — **if you can't run it, say so explicitly** rather than implying
success.

- Compare against the base branch rather than asserting: a pre-existing failing test or
  clippy error is not something you introduced, and saying so requires checking.
- `cargo build` finishing in under a second means it was cached, not that it rebuilt. Touch
  the sources when a rebuild is the thing you're verifying.

## PR / CI discipline

After any push or PR, **check CI and don't call it done until it's green**:

```bash
gh pr view <number> --repo pathscale/api.support.cafe --json statusCheckRollup
```

CI running → wait and recheck. CI failed → read the logs, fix, push, wait for green.
**Always paste the full PR URL** (`https://github.com/pathscale/api.support.cafe/pull/<n>`), not just
the number, so it's clickable.

## Keeping docs honest

Hit a factual error here — a stale path, a wrong command, a moved status? Fix it in the same
change. Don't open cosmetic rewording PRs.

Learned something durable — a gotcha, a decision, a constraint? It belongs **in this repo's
docs**, not in your agent's private memory. Repo docs are versioned, reviewable, and visible
to every agent and human; private memory dies with your machine.

## Guardrails

[`.claude/settings.json`](.claude/settings.json) and
[`.claude/hooks/`](.claude/hooks/) make Claude Code prompt a human before prod-affecting or
destructive commands — pushes, `cargo publish`, `gh pr merge`, cloud CLIs, recursive
deletes, deploy scripts.

**Other agents don't get that net automatically.** Apply the same rule yourself: ask before
running any command family listed in
[`.claude/hooks/ask-before-risky-commands.sh`](.claude/hooks/ask-before-risky-commands.sh).
It is one layer of defence, not a guarantee — a pattern match over a command string is
best-effort.
